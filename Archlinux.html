ARCH LINUX + NVIDIA GTX 1050 TI OPTİMİZE

REHBER (2025)

 

1. NVIDIA SÜRÜCÜ KURULUMU

 

Sistemi güncelleyin:

sudo pacman -Syu

 

NVIDIA için gerekli paketler:

sudo pacman -S nvidia-prime

 

Hibrit sistemlerde prime-run ile NVIDIA kullanılır.

 

 2. GÜVENLİ GRUB PARAMETRELER

 

Wayland ve NVIDIA için minimum güvenli parametre:

 

GRUB_CMDLINE_LINUX_DEFAULT="loglevel=3 quiet nowatchdog nvme_load=YES zswap.enabled=0 nvidia-drm.modeset=1 nvidia-drm.fbdev=1"

 

3. MODPROBE AYARLARI

 

Dosya:

kate /etc/modprobe.d/nvidia.conf

 

İçerik:

options nvidia-drm modeset=1

options nvidia NVreg_PreserveVideoMemoryAllocations=1

 

4. MKINITCPIO AYARLARI

 

MODULES satırı:

MODULES=(nvidia nvidia_modeset nvidia_uvm nvidia_drm)

 

Initramfs güncelleme:

sudo mkinitcpio -P

 

5. SSD TRIM

Trim aktif ederek SSD ömrü artırılır:

 

sudo systemctl enable --now fstrim.timer

 

6. SWAPPINESS

 

Dosya:

kate /etc/sysctl.d/99-swappiness.conf

 

 

 

İçerik:

vm.swappiness=10

vm.vfs_cache_pressure=50

 

7. ZRAM KURULUMU

 

sudo pacman -S zram-generator

kate /etc/systemd/zram-generator.conf:

 

İçerik:

[zram0]

zram-size = min(ram / 2, 4096)

compression-algorithm = zstd

 

8. DOSYA İNDEX KAPATMA

 

Tam kapatma:

System Settings → Search → File Search → File Indexing → false

 

9. KDE + KWIN OPTİMİZASYONU

 

Kapatılacak efektler:

• Blur (bulanıklık)

• Magic Lamp

 

10. NVIDIA İLE UYGULAMA ÇALIŞTIRMA

 

prime-run uygulama_adi

 

Örnek:

 

prime-run steam

 

prime-run blende
